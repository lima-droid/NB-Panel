## 安装

```bash
bash <(curl -sL 'https://raw.githubusercontent.com/lima-droid/NB-Panel/main/install.sh')
```

## 使用说明

### 龙虾面板 (nbpanel)

启动 Web 面板：

```bash
chmod +x /opt/lobster-panel/nodepassdash
/opt/lobster-panel/nodepassdash
```

默认端口: 4000  
默认账号: nbpanel / Np123456

### 龙虾核心 (np-master)

```bash
bash <(wget -qO1 https://raw.githubusercontent.com/lima-droid/NP-Master/main/scripts/np.sh) -i
```
